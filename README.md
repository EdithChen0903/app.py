# MOL AI Replenishment Agent - Streamlit Prototype
AI Strategy Lab Team 23, Assignment 1

Interactive prototype for agentic AI two-echelon replenishment for MOL Czech filling stations.

Features:
- Network & station KPIs dashboard
- AI reorder recommendations (Auto Approve / Escalate)
- AI transparency reasoning panel
- Manager decision workflow + feedback learning log
- Ecosystem map showing MOL as Orchestrator

Run on Streamlit Community Cloud.
